当前实现与参考

方案依据：源码样本与官方资料

本页汇总了各模块教程引用的开源仓库固定提交（Commit）与官方文档链接，方便读者直接对照源码核查实现细节。

核对日期：2026-10-18。以下样本服务于各模块原理教程中的方案对比与演进设计。

1. 引用依据的三种标注方式

  • 源码核对（固定 Commit）：直接链接到指定提交哈希下的源码文件与核心函数，避免主分支（main）后续变动导致链接失效。阅读时建议从入口函数顺着调用链查看状态更新、失败分支与落盘位置。
  • 官方文档：依据核对日公开的官方架构与机制说明，不揣测未公开的内部 Prompt 或隐藏阈值。
  • 本项目演进设计：针对 Learn Agent 的教学目标与阶段规划提出的设计方案，与上述外部产品实测区分开。

2. 指定版本的开源源码样本

pi：精简循环与可扩展 Harness

固定提交：9d2ec7ffabe927bfad2214c1cee25b6632a78dcf（2026-08-13）：

  • agent-loop.ts：streamAssistantResponse、transformContext 与 convertToLlm 的调用顺序，以及工具串行/并行分发。
  • Harness compaction.ts：shouldCompact、findCutPoint、prepareCompaction 及摘要生成逻辑。
  • session/context.ts：buildSessionContext 将最新压缩条目（含 retainedTail）与后续消息重建为模型输入。
  • session-format.md：JSONL 会话存储、父子条目、分支与格式兼容说明。

Deep Agents：基于中间件组合 Harness 能力

固定提交：97f856dcb08264ef78722a4687cab9133ec5fb7a（2026-10-18）：

  • graph.py：create_deep_agent 装配内置/自定义中间件、模型、存储后端与子 Agent。
  • summarization.py：compute_summarization_defaults、wrap_model_call，以及摘要事件、历史原文另存与输入预算控制。
  • filesystem.py：wrap_tool_call 拦截超大工具结果并另存，解耦文件工具与底层存储后端。
  • memory.py：before_agent 加载配置的记忆文件，modify_request 注入本轮请求。
  • skills.py 与 subagents.py：Skill 元数据发现、子任务独立输入构建与结果回传。

AgentScope Java：工作区、上下文预算与会话日志

固定提交：40a4a57ad79e82f8505572d3b195d0264ec7efcb（2026-10-18，注：对应 Java 仓库 v2 Harness，与 AgentScope Python 接口不同）：

  • context.md：稳定指令、动态数据源、优先级筛选与最终请求预算。
  • CompactionMiddleware.java：模型请求前的上下文压缩触发与超限处理。
  • ConversationCompactor.java：旧工具结果裁剪、摘要生成与保持工具调用/回执成对。
  • memory.md、session-log.md 与 subagent.md：长期记忆整理、持久化执行日志与子任务隔离说明。

3. 官方文档与协议规范对照

参考对象 采用的公开文档依据 阅读边界提醒
Claude Code 运行机制、记忆、子 Agent、权限、沙箱、Hooks 仅参考公开行为机制，不推断未公开的内部压缩 Prompt 或固定阈值
Codex 配置参考中的自动压缩阈值、上下文窗口与供应商配置 不同终端形态（CLI / 桌面 / 云端）可能存在内部实现差异
OpenAI Responses API 函数调用、服务端原生压缩 属于特定协议端点能力，不同于通用 Chat Completions 接口
OpenAI Agents SDK 运行循环、编排与 Handoff、观测 区分客户端 SDK 编排与服务端 API 的职责层次
LangGraph / LangChain 持久化、中断恢复、Graph API、中间件、长期记忆 保存节点检查点不等于自动保证外部非幂等工具只执行一次
