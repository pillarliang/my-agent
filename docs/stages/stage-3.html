阶段 3 导读：先实现会话与记录

1. 先完成什么

先完成“退出程序后仍能接着聊”：保存消息与工具回执，让同一会话的新任务使用历史。当前代码到阶段 2；3A 先明确数据、保存与查询契约，再动手实现。预算与裁剪留到 3B。

2. 两部分的分工

部分状态解决的问题
3A：会话与记录设计练习记录怎样保存、查询和用于追问
3B：上下文管理与预算后续设计历史太长时，本次选择哪些内容发送

存储与输入选择可以分开实现：3B 可以先处理内存消息；裁剪本次输入不应删除原始记录。

3. 阅读入口

先读模块原理与 pi / Codex 对照，再看 3A 的拟选方案、读取与追问设计和接入位置。出现长对话需求后，再看 3B。

4. 验证入口

当前单次循环命令与未来验收要求集中在 3A：运行与验证。会话保存、跨任务历史与自动恢复均未实现。
