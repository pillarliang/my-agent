Current Implementation & Reference

Design Basis: Source Samples & Official Docs

This page collects pinned commits from open-source repositories and official documentation links cited across module tutorials so readers can inspect implementation details directly against source code.

Verification date: 2026-10-18. The samples below support design comparisons and evolution decisions in the module principle tutorials.

1. Three Ways Evidence Is Cited

  • Source code verification (pinned commit): Links directly to source files and core functions under a pinned commit hash so subsequent changes on main never break references. When reading, trace from the entry function down the call chain to inspect state updates, failure branches, and persistence points.
  • Official documentation: Relies on publicly documented architecture and mechanisms as of the verification date without speculating about undocumented internal prompts or hidden thresholds.
  • This project's evolution design: Architectural choices tailored to Learn Agent's pedagogical goals and stage roadmap, explicitly distinguished from external product measurements.

2. Pinned Open-Source Code Samples

pi: Minimal Loop & Extensible Harness

Pinned commit: 9d2ec7ffabe927bfad2214c1cee25b6632a78dcf (2026-08-13):

  • agent-loop.ts: Call order of streamAssistantResponse, transformContext, and convertToLlm, plus sequential/parallel tool dispatch.
  • Harness compaction.ts: shouldCompact, findCutPoint, prepareCompaction, and summary generation logic.
  • session/context.ts: buildSessionContext reconstructing model input from the latest compaction entry (including retainedTail) and subsequent messages.
  • session-format.md: JSONL session storage, parent-child entries, branching, and format compatibility notes.

Deep Agents: Composing Harness Capabilities via Middleware

Pinned commit: 97f856dcb08264ef78722a4687cab9133ec5fb7a (2026-10-18):

  • graph.py: create_deep_agent wiring built-in/custom middleware, models, storage backends, and subagents.
  • summarization.py: compute_summarization_defaults, wrap_model_call, summarization events, offloading raw history, and input budget control.
  • filesystem.py: wrap_tool_call intercepting and offloading oversized tool results while decoupling file tools from underlying storage backends.
  • memory.py: before_agent loading configured memory files and modify_request injecting them into the current request.
  • skills.py and subagents.py: Skill metadata discovery, isolated subtask input construction, and result return.

AgentScope Java: Workspace, Context Budget & Session Logs

Pinned commit: 40a4a57ad79e82f8505572d3b195d0264ec7efcb (2026-10-18, note: corresponds to the Java repository v2 Harness, which differs from the AgentScope Python API):

  • context.md: Stable instructions, dynamic data sources, priority filtering, and final request budgets.
  • CompactionMiddleware.java: Triggering context compaction and handling budget overflow before model requests.
  • ConversationCompactor.java: Trimming old tool results, generating summaries, and keeping tool calls/receipts paired.
  • memory.md, session-log.md, and subagent.md: Long-term memory organization, persistent execution logs, and subtask isolation notes.

3. Official Documentation & Protocol Specification Comparison

Reference Target Public Documentation Basis Reading Boundary Reminder
Claude Code How it works, Memory, Subagents, Permissions, Sandboxing, Hooks Refer only to publicly documented behavior; do not infer undisclosed internal compaction prompts or fixed thresholds
Codex Auto-compaction thresholds, context windows, and provider configuration in the Config Reference Different surfaces (CLI / Desktop / Cloud) may have internal implementation differences
OpenAI Responses API Function calling, Server-side native compaction Specific protocol endpoint capabilities, distinct from the general Chat Completions interface
OpenAI Agents SDK Running agents, Orchestration & Handoffs, Observability Distinguish responsibility layers between client-side SDK orchestration and server-side APIs
LangGraph / LangChain Persistence, Interrupts, Graph API, Middleware, Long-term memory Saving node checkpoints does not automatically guarantee exactly-once execution for external non-idempotent tools
Letta / MemGPT MemGPT Paper, Letta Repository Reference for OS-style hierarchical memory and self-editing tools; practical implementations require guardrails against hallucinated facts and spurious tool calls
Standard Protocols & Observability / Evals MCP 2025-11-25, Agent Skills, OpenTelemetry Trace, GenAI Semantic Conventions, Evaluation best practices Even after adopting standard protocols, the host remains responsible for permission interception and business outcome verification
