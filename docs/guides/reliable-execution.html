二、Harness 核心模块
Interfaces：让不同用户入口共用执行流程Loop / Runner：控制一次任务怎样继续和停止Model：适配模型服务与通信协议Tools：执行模型提出的工具调用Policy：在执行前检查操作权限Session / State：管理会话与执行记录Context Manager：组织本次发给模型的内容Quality：观测与评测
三、进阶扩展模块
Memory：选择跨会话保留的知识可靠执行与隔离Recovery：中断检查点、异常容错与安全恢复Extensions：接入 Skills、Hooks 和外部工具Orchestration：安排多个 Agent 分工与协作
