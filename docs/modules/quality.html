Quality：观测与评测

1. 核心架构升级：观测与评测正式拆分为两个独立模块

在 Agent 系统设计中，观测（Observability） 与 评测（Evaluation） 是两套生命周期不同、关注维度不同、技术方案完全独立的工程模块：

  • 观测回答“运行中实际发生了什么”：发生在线上运行时，关注 Trace 调用树、Token 消耗细则、延迟切片与错误回溯。
  • 评测回答“任务结果是否真正达标”：发生在离线与预发布阶段，依赖沙箱环境隔离、真实环境状态断言（State Diff）与多维质量评估。

为了让知识结构更清晰、职责边界更彻底，本项目已将 Quality 专题正式拆分为两篇独立的深入模块：

👉 Observability：运行时全链路观测与追踪

深入介绍 Trace、Generation、Span、Score 四层抽象，结合 Langfuse 开源实践讲解调用链拓扑可视化、实时成本监控与异步非阻塞上报。

👉 Evaluation：Agent 任务评测与沙箱断言

深入介绍 Agent 评测区别于传统 LLM 评测的本质断层，结合 Inspect AI、DeepEval 与 SWE-bench 等开源方案，完整拆解“沙箱隔离 → 动态执行 → 多维打分断言 → 报告输出”闭环。
