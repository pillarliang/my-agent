## 4. 当前没有验证的边界

真实模型无法保证按要求生成重复调用 ID、空响应、拒答或服务端限流，因此当前不声明这些分支已经由本轮测试稳定覆盖；精确发生在某个 I/O 中途的取消和超时，也没有确定性覆盖。代码仍保留对应保护，但覆盖范围应与可重复证据分开说明。

MVP 没有操作系统沙箱、自动恢复、账户费用硬上限或多租户身份系统，因此没有这些能力的验证结论。模型更新、网络状态和非确定性都可能改变真实集成测试结果，重跑时应保留失败信息。

文档检查器检查本地路径与代码围栏，章节锚点另外核对；它不解析完整 Mermaid 语法，也不自动评价表达质量。图示与正文仍需结合实际代码审阅。

## 5. 怎样重跑

运行 `uv run pytest -m "not live"` 仅检查本地组件，运行 `uv run pytest` 则同时执行真实模型集成测试；标记只用于选择案例，不提供替代模型。缺少凭证的真实测试会明确跳过，不能算作通过。

运行 `uv run python scripts/evaluate.py` 会实际执行三个模型任务并产生 API 调用。比较版本时，应记录模型、配置、样本数、日期、用量和全部失败案例；临时任务文件与数据库会在结束后删除，需要保留的汇总应另外保存。
